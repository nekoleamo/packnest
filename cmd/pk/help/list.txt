pk list [工具] [--major N] [--available] [--refresh] [--all|--limit N] [--json]

  不带参数：列出已装工具（* 是当前全局默认），带版本占用空间。这个不带网络。
  pk list node：只看 node —— 已装版本 + 可装版本，旧 → 新、最新在最下面；
                版本 ≤40 个时一版一行（带 latest / lts: <代号> / 已装 标签），
                更多时自动换成「按大版本分组 + 多列网格」（列数按终端宽度算），
                标记：* 最新 · l LTS · + 已装 · @ 当前默认。
