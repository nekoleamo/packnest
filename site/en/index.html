What it solves

China network
Five built-in profiles: default / cn / tuna / aliyun / ustc. The first install probes for real (500ms HEAD, cached for 6h): reachable upstream means direct, otherwise it falls back to a domestic mirror automatically.
npm pairing
npm is not a standalone tool but a companion of Node: the newest npm compatible with the exact Node version is looked up and replaces the older one shipped in the tarball (boundaries are patch-level, pre-releases excluded).
Checksums
The first install requires at least two sources to agree on the digest and records it in a TOFU table; every later install of that version verifies fully offline. If sources disagree it fails hard and tells you which source the artifact actually matches.
Uninstall
The ledger is the only source of truth: only directories it recorded are removed, version switches are atomic shim re-points, and uninstalls leave zero residue. pk uninstall --all --self removes pk itself too (delayed delete on Windows).
Long tail
Six providers are embedded; everything else comes from your own TOML manifest (~/.packnest/providers/<id>.toml) — index, artifact, checksums, layout and companion packages are declarative data, no code executed. Field reference: docs/providers.md.
Downloads
Range resume, single stream by default; --jobs N shards the download (needs ≥8MB and Range support, falls back to one stream on any trouble). Measured on a 48MB node tarball: 1.46s → 0.84s with 8 shards.
Footprint
One Go binary with CGO_ENABLED=0, built for six targets, depending on exactly two third-party libraries (semver, toml).

envprints a shell snippet; --write updates the managed block (on Windows the user Path registry value, immune to ExecutionPolicy)
gcreclaims unreferenced versions and over-limit cache

Global flags: --json (the only contract for GUIs and scripts) · --offline · --yes · --root. Fixed exit codes: 0 ok / 1 generic / 2 usage / 3 network / 4 checksum / 5 locked.

Long-tail tools need no release: drop ~/.packnest/providers/<id>.toml in (pure data, no code executed; checksums, mirror fallback and companion packages are declared in the manifest, and pk doctor points at the offending line).
