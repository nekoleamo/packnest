What it solves

China network
Five built-in profiles: default / cn / tuna / aliyun / ustc. The first install probes for real (500ms HEAD, cached for 6h): reachable upstream means direct, otherwise it falls back to a domestic mirror automatically.
npm pairing
npm is not a standalone tool but a companion of Node: the newest npm compatible with the exact Node version is looked up and replaces the older one shipped in the tarball (boundaries are patch-level, pre-releases excluded).
Checksums
The first install requires at least two sources to agree on the digest and records it in a TOFU table; every later install of that version verifies fully offline. If sources disagree it fails hard and tells you which source the artifact actually matches.
Uninstall
The ledger is the only source of truth: only directories it recorded are removed, version switches are atomic shim re-points, and uninstalls leave zero residue.
Footprint
One Go binary with CGO_ENABLED=0, built for six targets, depending on exactly two third-party libraries (semver, toml).

toolnotes
nodeofficial index + China mirrors; npm is auto-paired on install
npmonly appears as Node's companion; never exposed as its own version
pnpmneeds Node first (runtimes are never installed implicitly); PNPM_HOME points at the shared prefix
bunsingle-file layout, official releases with mirror fallback
denosingle-file layout; versions the upstream re-published are rejected when two sources disagree — use --insecure if you accept the risk
gowrites GOTOOLCHAIN=local into your environment so Go does not fetch a second toolchain
pythoninstalls python-build-standalone prebuilt builds only, never compiles from source
