它解决什么

国内网络
内置 default / cn / tuna / aliyun / ustc 五档。装第一个工具时做真实探测（500ms HEAD，结果缓存 6h）：官方源通就直连，不通自动落国内档。
npm 配对
npm 不是独立工具，是 node 的伴生包：按 node 的精确版本反查「最新兼容的 npm」，替换掉发行版自带的旧版（按补丁号判分界，排除预发布）。
校验
首次安装要求至少两个源给出相同摘要并写进 TOFU 表，之后同一版本完全离线可验证；源之间矛盾时硬失败，并告诉你产物与哪个源一致。
卸载
台账是唯一事实源：只删自己记录过的目录，切版本靠 shim 原子重指，卸载回到零残留。
体积
单个 Go 二进制，CGO_ENABLED=0，六平台构建，只依赖两个第三方库（semver、toml）。

能装什么 7 providers · 内嵌 TOML 声明

工具说明
node官方索引 + 国内镜像；装完自动配对 npm
npm只作为 node 的伴生包出现，不单独暴露一个版本
pnpm需要先有 node（不隐式安装运行时），PNPM_HOME 指向共享前缀
bun单文件布局，官方 release + 镜像回退
deno单文件布局；上游重新发布过的版本会因两源摘要不一致被拒，需要时用 --insecure
go装完把 GOTOOLCHAIN=local 写进环境，避免它自己去下一套工具链
python只装 python-build-standalone 预编译版，永不源码编译

In English

packnest (command pk) installs Node/npm/pnpm/bun/deno/Go/Python as a single zero-CGO Go binary for six platforms, with only two third-party dependencies. It ships China mirror presets plus real reachability probing, pairs the newest npm compatible with the exact Node version being installed, verifies artifacts against multiple checksum sources (TOFU, offline-verifiable afterwards), and uninstalls back to zero residue.
Install: npm i -g packnest && pk install node@22 — or curl -fsSL https://gitee.com/null_593_5354/packnest/raw/main/scripts/install.sh | sh.
