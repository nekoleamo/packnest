packnest

国内网络开箱可用的多语言运行时安装器v__PK_VERSION__

命令行叫 pk（也提供 packnest 别名）。与 NestJS 无关。

安装

npm i -g packnest
pk install node@22

不想用 npm：走 gitee 直取，全程不访问 GitHub。

curl -fsSL https://gitee.com/null_593_5354/packnest/raw/main/scripts/install.sh | sh

Windows PowerShell：

iwr https://gitee.com/null_593_5354/packnest/raw/main/scripts/install.ps1 -UseB | iex

或者 brew install nekoleamo/packnest/packnest · scoop install packnest

它解决什么

国内网络
内置 default / cn / tuna / aliyun / ustc 五档。装第一个工具时做真实探测（500ms HEAD，结果缓存 6h）：官方源通就直连，不通自动落国内档。
npm 配对
npm 不是独立工具，是 node 的伴生包：按 node 的精确版本反查「最新兼容的 npm」，替换掉发行版自带的旧版（按补丁号判分界，排除预发布）。
校验
首次安装要求至少两个源给出相同摘要并写进 TOFU 表，之后同一版本完全离线可验证；源之间矛盾时硬失败，并告诉你产物与哪个源一致。
卸载
台账是唯一事实源：只删自己记录过的目录，切版本靠 shim 原子重指，卸载回到零残留（连空的版本目录一起收掉）。
体积
单个 Go 二进制，CGO_ENABLED=0，六平台构建，只依赖两个第三方库（semver、toml）。

能装什么

工具说明
node官方索引 + 国内镜像；装完自动配对 npm
npm只作为 node 的伴生包出现，不单独暴露一个版本
pnpm需要先有 node（不隐式安装运行时），PNPM_HOME 指向共享前缀
bun单文件布局，官方 release + 镜像回退
deno单文件布局；上游重新发布过的版本会因两源摘要不一致被拒，需要时用 --insecure
go装完把 GOTOOLCHAIN=local 写进环境，避免它自己去下一套工具链
python只装 python-build-standalone 预编译版，永不源码编译

命令

命令做什么
install装工具；无参数时按当前目录的 pk.toml 全装并刷新 pk.lock
uninstall台账驱动卸载（被引用的版本需要 --force）
use切换全局默认版本；--project 固定到当前项目
list已装工具与占用空间；--available 列各工具最新可装版本
which把 shim 解析回真实二进制路径
mirrorlist / probe / use / write 四个子命令管理镜像档
doctor体检 PATH、台账、镜像、全局包、其他版本管理器
env输出 shell 片段；--write 才写进 rc 的托管块
gc回收零引用版本与超限缓存
