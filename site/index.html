它解决什么

国内网络
内置 default / cn / tuna / aliyun / ustc 五档。装第一个工具时做真实探测（500ms HEAD，结果缓存 6h）：官方源通就直连，不通自动落国内档。
npm 配对
npm 不是独立工具，是 node 的伴生包：按 node 的精确版本反查「最新兼容的 npm」，替换掉发行版自带的旧版（按补丁号判分界，排除预发布）。
校验
首次安装要求至少两个源给出相同摘要并写进 TOFU 表，之后同一版本完全离线可验证；源之间矛盾时硬失败，并告诉你产物与哪个源一致。
卸载
台账是唯一事实源：只删自己记录过的目录，切版本靠 shim 原子重指，卸载回到零残留；pk uninstall --all --self 连 pk 自己一起清（Windows 上延时删除）。
长尾工具
内嵌 6 个 provider，其余靠 自写 TOML 清单（~/.packnest/providers/<id>.toml）：索引、产物、校验、布局、伴生包全在清单里声明，纯数据不执行代码；字段见 docs/providers.md。
下载
Range 续传 + 默认多连接（≥8MB、冷启动、源支持 Range 时按大小自适应 2~8 段，异常自动退回单流；--jobs 1 可强制单流）。实测 48MB 的 node 包：单流 1.46s → 8 段 0.84s。
体积
单个 Go 二进制，CGO_ENABLED=0，六平台构建，只依赖两个第三方库（semver、toml）。

命令做什么
install装工具；无参数时按当前目录的 pk.toml 全装并刷新 pk.lock
uninstall工具@版本 删一个；工具 删该工具全部版本（先列版本再确认）；--all 清掉一切（--purge 连根删、--self 连自己）
use切换全局默认版本；--project 固定到当前项目
list已装工具与占用空间，版本落后时提示可升级（只读索引缓存、不联网）；pk list node 看单个工具的全部可装版本（--major 22 / --all）
which把 shim 解析回真实二进制路径
mirrorlist / probe / use / write 四个子命令管理镜像档
doctor体检 PATH、台账、镜像、全局包、其他版本管理器；--fix 自动修 PATH 托管块与 pk/packnest 入口
env输出 shell 片段；--write 写进托管块（Windows 走注册表用户 Path，不受执行策略限制）
gc回收零引用版本与超限缓存；--keep 2 每个工具保留最新 2 个
upgrade把已装工具一次升到索引最新（旧版本保留、全局默认跟着切、npm 随 node）；--dry-run 先看要升什么

全局开关 --json（GUI 与脚本的唯一契约）· --offline · --yes · --root；退出码固定 0 成功 / 1 通用 / 2 用法 / 3 网络 / 4 校验 / 5 锁被占用。

长尾工具不用等发版：把 ~/.packnest/providers/<id>.toml 放进去即可（纯数据、不执行代码；校验和、镜像回退、伴生包都在清单里声明，pk doctor 会指出清单哪一行不对）。

桌面端 可选 · 独立产物 · 必须先装 CLI

GUI（pk-desktop，Wails + Vue3）只是 CLI 的可视化补充：不 import 任何内部包， 每个操作都是子进程调 pk <命令> --json，业务真相始终在 CLI 和 ~/.packnest 里。 所以它永远比 CLI 晚半步，也不会替你下载第二份运行时。

能做什么
已装工具表（含 可升级 提示，点一下就 pk install <工具>@latest）、多 spec 安装队列与每行进度、 镜像档切换 + 各源延迟探测、体检页（全局包表格化、--probe 用 node 实测原生模块、一键修复 = pk doctor --fix）、 回收页（预演/真删、--keep N 每个工具保留最近 N 个版本）、which 与 env 只读查看、 深浅色切换、中英双语（顶栏切换，默认跟系统语言）、开机自启（默认关，只写用户级条目）。
下载
独立 tag gui-v__GUI_VERSION__，三个产物： packnest-desktop___GUI_VERSION___darwin_arm64.app.zip、…_windows_amd64.zip、…_linux_amd64.tar.gz —— 从 gitee 或 GitHub 取。
前置条件
先装 CLI（pk）—— 没装时界面顶部会直接给出当前平台的安装命令（Windows 走 PowerShell，其余走 sh）并带复制按钮。macOS 是 ad-hoc 签名，首次打开要在 「系统设置 → 隐私与安全性」放行一次；Linux 需要 GTK4 + WebKitGTK 6.0（libgtk-4-dev libwebkitgtk-6.0-dev）。 不想装桌面运行时也能用浏览器形态：pk-desktop --serve → http://127.0.0.1:7799/，功能与桌面壳一致。
不是什么
不是第二个安装器：没有自己的下载器、台账或更新器；卸载/升级仍指回 CLI（brew upgrade packnest、 pk uninstall --all --self）。

In English

packnest (command pk) installs Node/npm/pnpm/bun/Go/Python as a single zero-CGO Go binary for six platforms, with only two third-party dependencies. It ships China mirror presets plus real reachability probing, pairs the newest npm compatible with the exact Node version being installed, verifies artifacts against multiple checksum sources (TOFU, offline-verifiable afterwards), and uninstalls back to zero residue — pk uninstall --all --self even removes pk itself.
Install: curl -fsSL https://gitee.com/null_593_5354/packnest/raw/main/scripts/install.sh | sh (Windows: iwr https://gitee.com/null_593_5354/packnest/raw/main/scripts/install.ps1 -UseB | iex) — or via Homebrew / Scoop.
